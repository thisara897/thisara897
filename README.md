# ⚡ Featured — 3D Product Configurator

<div align="center">

> A scroll-driven 3D product page for an electric vehicle launch. The model stays locked behind the page and rotates, opens and reveals itself as you scroll — no separate "viewer" section, the whole page *is* the viewer.

**What's under the hood**

- 🎛 Full configurator — orbit controls, live colour swatches, animated door rigs, spec hotspots
- 🌘 Dim natural lighting rig instead of the usual blown-out studio HDRI
- 🎬 Scroll-linked animation timeline driving camera position and model state
- 📦 Optimised GLB assets, draco-compressed so it loads fast on mobile
